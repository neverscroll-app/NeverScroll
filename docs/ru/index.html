Открой. Посмотри. Вернись.

Защита включается на распознанном экране короткого видео. Никаких счётчиков роликов и таймеров.

01

Открой ссылку

Перейди к ролику из мессенджера как обычно.

02

Посмотри ролик

Свайпы заблокированы. Короткие нажатия, например пауза и комментарии, по возможности работают.

03

Вернись назад

Кнопка выхода всегда сверху. В TikTok она открывает недавние приложения, в остальных — «Назад».

Где работает

Выбирай приложения, в которых нужна защита. Распознавание осторожное, чтобы обычные экраны оставались доступными. После обновления другого приложения ролик может не распознаться.

  • YouTubeShorts
  • YouTube ReVancedShorts по прямой ссылке
  • InstagramReels
  • TikTokЛента «Для вас»

Данные остаются на устройстве.

NeverScroll использует службу специальных возможностей Android, чтобы читать элементы открытого экрана выбранных приложений и накладывать прозрачную область на распознанные ленты. Приложение не делает скриншоты, не сохраняет историю просмотров, не использует аналитику и никуда не отправляет данные. Настройки хранятся на устройстве.

Если ролик не распознан, дополнительный режим совместимости может блокировать свайпы на всех экранах этого приложения, включая сообщения и обычную ленту. По умолчанию он выключен.

Настрой один раз.

Установи APK, открой NeverScroll и после ознакомления с уведомлением включи службу специальных возможностей. Защиту можно отключить в любой момент.
